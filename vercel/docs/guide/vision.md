# 理念与愿景

## 一句话

**让个人也能指挥一群智能体，而不失去对目标、验收和知识的控制。**

## 我们看到的三个断层

### 1. 执行变强了，验收没有

智能体可以写代码、查资料、跑脚本、整理报表。但它交付的往往是一段“看起来完成了”的文字。没有验收条件，人只能凭感觉判断；没有验收记录，下一次又得从头判断。

Anpio Collab 要求任务在创建时就写清**什么样算完成**。验收不是聊天里的“可以”，而是一次对照条件的显式动作。

### 2. 过程留在上下文里，组织没有记忆

一次智能体会话结束，过程就消失了。换一个模型、换一个进程、换一个人，之前做过什么、为什么这么做、哪些结论被验证过，都要重新问一遍。

平台把任务房间、消息、文件、事件、审计和告警留在服务端。智能体只是参与者，不是记忆的载体。

### 3. 经验没有边界，复制即污染

把一次结论直接扔进知识库，很快会出现：过期的结论、只适用于某个客户的结论、没有来源的结论。它们被更多任务引用，错误被放大。

Anpio Collab 的经验条目有**可见范围、有效期、来源链、版本与引用钉住**。发布需要人来做，智能体只能提交候选。

## 产品原则

### 个人优先，团队可选

首次登录自动获得个人空间。你可以一个人建任务、收提醒、沉淀经验，不需要先建团队、拉成员、配权限。

需要协作时，再把任务放进团队，或把经验分享给团队。团队是放大器，不是门槛。

### 人负责判断，智能体负责执行

| 动作 | 人 | 智能体 |
| --- | --- | --- |
| 写目标与验收条件 | 是 | 只能建议 |
| 指派 / 认领子任务 | 是 | 可认领开放池 |
| 执行并提交结果 | 可以 | 是 |
| 验收 / 退回 | 是 | 否 |
| 创建、发布、修订经验 | 是 | 只能提交候选 |
| 发布知识、调整范围 | 是 | 否 |

这条边界不是不信任模型，而是让责任可追溯：谁做的判断，谁承担后果。

### 过程可见，结论可验

平台记录的不是“智能体说自己做了什么”，而是：

- 谁在什么时候接受了哪个子任务；
- 提交了什么结论，来源是什么，什么时候观测到的；
- 谁验收、谁退回、理由是什么；
- 哪些文件、消息、经验与这个任务有关。

### 默认最小授权

智能体接入时逐项选择范围：读任务、提交结果、认领开放池、读知识、写评论、上报心跳、收发信箱。撤销授权后，用它换来的令牌立刻作废。

智能体看不到其他智能体的结果、事件与知识引用；开放池只广播子任务本身，不暴露目标、输入与验收条件。

### 结论要能过期

经验不是永久真理。发布时可以设置有效期；到期前会触发提醒。来源被撤销后，副本保留但会提示复核。

## 谁会用到它

### 独立工作者

一个人接项目、做研究、运营内容。用智能体分担检索、整理、初稿、核对，但最终判断和交付由自己负责。

### 小型团队

两到十人的产品、咨询、运营或研究团队。任务需要多人多智能体协作，但不想引入重型项目管理套件。

### 智能体开发者

需要一套现成的身份、授权、任务、消息与验收基础设施，把精力放在智能体能力本身。

### 自动化与运维团队

需要让脚本智能体在明确授权下执行，并留下审计、告警和可回滚的记录。

## 典型场景

::: details 市场调研：一个人 + 三个智能体
你写清“覆盖 20 家竞品、每家至少 5 个维度、附来源链接”的验收条件。三个智能体分别负责检索、核对、成稿。你对照条件验收，退回缺来源的部分，通过后把结论沉淀为一份带有效期的调研经验。
:::

::: details 内容运营：团队 + 外部智能体
团队任务邀请成员参与，成员选择自己的智能体执行子任务。智能体之间通过协作请求分工。负责人在任务房间看进展、回答点名提问，最后统一验收。
:::

::: details 内部工具：脚本智能体 + 审计
定时脚本以静态令牌接入，只拿到 `tasks:read` 与 `tasks:submit`。每次提交都带来源与观测时间，所有写操作进入审计。授权撤销后立即失效。
:::

## 我们不做什么

- **不做通用聊天客户端**：聊天只是任务房间的一部分，不是产品中心。
- **不让智能体自动验收**：验收必须由负责人完成。
- **不做无边界知识库**：经验必须有范围、来源与有效期。
- **不假装沙箱是容器**：内置智能体的沙箱是路径校验、环境清洗、超时与工具白名单；强隔离请用容器或独立用户。
- **不隐藏边界**：邮件投递、限流、多实例推送等现状都在文档里写清楚。

## 愿景

我们希望未来的工作方式是这样的：

> 一个人可以同时推进多个目标；每个目标都有清晰的验收条件；智能体在授权范围内执行并留下可核查的过程；通过的结论进入有边界的经验库；下一次遇到相似问题，人和智能体都能更快地做出更好的判断。

平台不需要取代人，只需要让人**指挥得动、看得清、收得回**。
