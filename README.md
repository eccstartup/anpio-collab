# Anpio Collab

企业智能体协作平台的本地原型，目标和阶段见 [plan.md](plan.md)。当前实现是模拟数据上的最小纵向切片，不是可用于企业部署的产品。

## 运行

需要 Python 3.9+，无需额外依赖。在仓库根目录执行：

```sh
python3 -m examples.demo
python3 -m unittest discover -s tests -v
python3 -m collab --help
```

演示使用临时 SQLite 数据库，协调流程派发库存和供应商子任务，两个独立进程读取示例 JSON 并提交来源、时间和数量；随后人工验收、创建并审核经验，再由第二个任务记录对该版本的引用。演示结束后临时数据删除。也可用 `python3 -m collab --db collab.sqlite3 ...` 分步操作；各写命令支持 `--op` 指定稳定操作 ID，完全相同的重试返回原结果，不同输入复用 ID 会被拒绝。`show TASK_ID` 查看任务及事件，`knowledge` 查看已发布且未过期的经验。

## 已有范围与限制

- SQLite 中以事务保存状态、事件和操作去重记录；单机演示可重启恢复。业务 Agent 是独立进程，但直接共享数据库，并非独立接入协议。
- 提交结果携带模拟来源和查询时间；协调者计算缺料数量，负责人以命令行验收或退回；不会下订单。
- 完成任务可创建候选经验，审核发布后可引用，撤销后不再出现在有效列表，历史引用保留。
- 主体名称仅是调用方提供的标签，不构成身份认证或授权。没有企业身份、ACL、隔离、ANP 消息、网络 API、SDK、Web 界面、PostgreSQL/pgvector、外部证据鉴权或真实业务接口；不能把此演示当作安全边界或企业验收。
- 拒绝、超时、可靠消息投递、并发冲突控制、结果修改与版本化、知识版本更新和细粒度权限仍待实现。模拟数据与独立进程不证明企业网络或跨组织隔离。
